# Adeola Akinbola — Software Engineering Portfolio

A responsive, static portfolio website for GitHub + Vercel deployment.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a new GitHub repository (for example, `adeola-portfolio`).
3. Upload the contents of this folder to the repository root.
4. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy.
5. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (the project root).

## Update projects
Edit `index.html` and find the `SELECTED WORK` section. Duplicate a `<article class="project">...</article>` card for each new project, update its title, description, tags and link, and change the project number/type.

## Important accuracy notes
- SMTMApp is presented as a live product and founding-engineer contribution. Its source code is private.
- Glory Prime Estates and Real Estate Billionaires Network are labelled as website concepts, not confirmed client engagements.
- The Student Management System is labelled as an academic project in progress.
- No invented performance metrics, client outcomes or years of professional experience are claimed.
- Replace the LinkedIn URL if your current profile uses a different public slug.
